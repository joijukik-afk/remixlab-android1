# RemixLab 🎵

**استودیوی ریمیکس توی جیبت**

اپلیکیشن حرفه‌ای ریمیکس موسیقی برای اندروید

---

## ✨ قابلیت‌ها

- 🎛️ **۱۰ پریست آماده COMA** (Deep Coma، Midnight Rain، Dark Dreamcore و...)
- 🎚️ **افکت‌های صوتی حرفه‌ای** (Slowed، Reverb، Bass Boost، 8D Audio)
- 🌧️ **۵ صدای محیطی** (باران، رعد، باد، نویز آنالوگ)
- 🤖 **دستیار هوشمند فارسی** (بدون نیاز به اینترنت)
- 💾 **خروجی MP3** با ۴ کیفیت (تا ۳۲۰ kbps)
- 📝 **نام‌گذاری و متادیتای دلخواه**
- 📤 **اشتراک‌گذاری آسان** (واتساپ، تلگرام، جیمیل)
- 🎨 **طراحی مدرن** با Jetpack Compose و Material 3
